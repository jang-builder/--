# 상세페이지 자동 생성기

상품 정보만 채우면 **스마트스토어 · 쿠팡에 바로 올리는 860px 상세페이지**가 만들어집니다.
판매 문구(헤드라인 · 공감 문장 · 혜택 카피 · FAQ)는 업종과 말투에 맞춰 자동으로 작성됩니다.

설치도, 회원가입도, 월 이용료도 없습니다. `index.html` 파일을 더블클릭하면 끝입니다.

---

## 한눈에 보기

| 무엇을 | 어떻게 |
|---|---|
| 사용 방법 | `detail-page/index.html` 더블클릭 (크롬 권장) |
| 나오는 결과 | 가로 860px 상세페이지 → PNG 이미지 또는 HTML 파일 |
| 문구 작성 | 업종 7종 × 말투 3종 패턴을 조합해 자동 생성 (외부 서비스·API 사용 안 함) |
| 인터넷 | 없어도 동작합니다 (이미지 저장까지 전부 브라우저 안에서 처리) |

---

## Step 1. 파일 열기

`detail-page/index.html`을 더블클릭하세요. 처음 열면 예시(소고기무국)가 채워져 있습니다.
**예시 내용을 지우지 말고 그 위에 덮어쓰는 방식**이 가장 빠릅니다.

## Step 2. 기본 정보 입력 (3분)

왼쪽 패널의 `1. 기본 정보`부터 채웁니다.

- **업종 / 말투 톤** — 이 두 개가 문구 전체를 결정합니다.
  - `신뢰형` : 단골 장사, 식품, 병원처럼 "믿음"이 중요한 곳
  - `감성형` : 선물, 소품, 뷰티처럼 "기분"으로 사는 곳
  - `가성비형` : 생활용품, 대용량, 묶음 상품
- **주요 고객** — 구체적일수록 문구가 좋아집니다.
  `30대 여성`(X) → `혼자 사는 30대 직장인`(O)
- **메인 컬러** — 한 가지만 정하면 페이지 전체 색이 맞춰집니다. 로고 색을 그대로 쓰시면 됩니다.

## Step 3. 핵심 특징 3~5개 적기 (가장 중요)

`2. 핵심 특징`에 **사실만** 짧게 적으세요. 설명란은 비워두면 판매 문구가 자동으로 붙습니다.

> 국내산 한우 양지 25% 이상
> → 국내산 한우 양지 25% 이상. 처음 구매하시는 분도 실패하지 않는 이유입니다.

특징을 쓰실 때 요령: **"우리 가게만 쓸 수 있는 문장"**인지 확인하세요.
`신선한 재료`는 누구나 쓰지만 `오후 2시 이전 주문 당일 포장`은 우리만 씁니다.

## Step 4. 이미지 넣기

- **메인 이미지** 1장 : 첫 화면에 크게 들어갑니다. 정사각형 또는 4:3 권장
- **상세 이미지** 여러 장 : 가로 **860px**로 맞춰두면 잘림 없이 들어갑니다

사진은 브라우저 안에서만 처리되며 어디에도 전송되지 않습니다.
(대신 새로고침하면 사진은 다시 넣어야 합니다. 글자 입력값은 자동 저장됩니다.)

## Step 5. 문구 마음에 들 때까지 뽑기

상단 **🔁 문구 다시 뽑기**를 누를 때마다 헤드라인 · 서브 문구 · CTA가 다른 조합으로 바뀝니다.
말투 톤을 바꿔가며 눌러보시면 후보가 9가지 이상 나옵니다.

## Step 6. 저장하고 올리기

| 버튼 | 언제 쓰나 | 결과 |
|---|---|---|
| 📷 **이미지(PNG)로 저장** | 스마트스토어 · 쿠팡 | 860px PNG. 길면 2,400px씩 나눠서 여러 장으로 저장됩니다 |
| **HTML 저장** | 아임웹 · 카페24 · 자사몰 | 혼자서도 열리는 HTML 파일 1개 |
| **HTML 복사** | 에디터에 바로 붙여넣기 | 클립보드에 코드 복사 |

> 📷 로 여러 장이 저장되면 **파일명 번호 순서대로**(01, 02, 03…) 업로드하세요. 순서가 섞이면 페이지가 어긋납니다.

## 꼭 지켜야 할 것 (과태료 나옵니다)

- **후기는 실제 받은 것만** 넣으세요. 지어낸 후기는 표시광고법 위반입니다.
- `최저가`, `1위`, `100% 효과` 같은 표현은 **근거 자료가 없으면 쓰지 마세요.**
- 비교표의 "일반 제품"은 특정 경쟁사를 지칭하지 않도록 두었습니다. 상호를 직접 넣지 마세요.
- 식품 · 화장품은 **효능을 단정하는 표현**(치료, 개선, 완치)이 금지됩니다. 자동 문구에는 들어있지 않지만, 직접 쓰실 때 주의하세요.

## 파일 구조

```
detail-page/
├─ index.html              생성기 화면
├─ css/generator.css       생성기 UI 스타일
└─ js/
   ├─ copywriter.js        판매 문구 자동 작성 (업종·말투 패턴)
   ├─ detail-style.js      상세페이지 디자인 (860px)
   ├─ render.js            입력값 → 상세페이지 HTML 조립
   └─ app.js               입력·미리보기·저장 처리
```

## 내 가게에 맞게 고치기

- **문구를 우리 업종 말투로** : `js/copywriter.js`의 `CATEGORY`에서 업종별 `pains`(고민), `recos`(추천 대상), `faq`를 수정하세요.
- **업종 추가** : `CATEGORY`에 항목 하나를 복사해 붙여넣고 내용만 바꾸면 선택 목록에 자동으로 나타납니다.
- **디자인 변경** : `js/detail-style.js`의 글자 크기(`font-size`)와 여백(`padding`)만 건드려도 분위기가 크게 달라집니다.
- **섹션 순서 변경** : `js/render.js` 맨 아래 `ORDER` 배열의 순서를 바꾸면 그대로 반영됩니다.
